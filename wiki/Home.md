# UltraTerraForged × Alex's Caves — Wiki

Restores Alex's Caves underground biome and chamber generation within UltraTerraForged worlds.

**Minecraft 1.21.1 · NeoForge 21.1.219+ (21.1.x) · Java 21 · Documented version 1.0.0**

Compatible with the unofficial Alex's Caves NeoForge port 2.0.10.
